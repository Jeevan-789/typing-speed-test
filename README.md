# ⌨️ Typing Speed Test

A simple web app to measure typing speed and accuracy.

## 🚀 Features
- 60-second typing test
- Words per minute (WPM)
- Accuracy calculation

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## ▶️ Run
Open index.html in browser

## 💡 Future Improvements

- Difficulty levels
- Real-time WPM
